Sobre Mí

Soy Ricardo Zelaya, un estudiante comprometido con el dominio de las herramientas de productividad Microsoft Office, actualmente en preparación para obtener la certificación Microsoft Office Specialist (MOS). Mi interés por la tecnología me ha llevado a explorar no solo el uso estándar de las aplicaciones, sino también su integración con Inteligencia Artificial para optimizar procesos y elevar la calidad del trabajo profesional. A lo largo de este portafolio presento una selección de documentos que demuestran mi capacidad para estructurar, analizar y presentar información de manera efectiva.

Cómo Usé la IA

La integración de Inteligencia Artificial, específicamente Claude, fue un pilar en cada etapa de mi preparación y en la creación de este portafolio.

1. Ideación

Utilicé sugerencias de documentos y lluvia de ideas con IA para estructurar los proyectos que conforman este portafolio y los requerimientos MOS.

2. Redacción

Apoyo en la creación de textos formales, cartas, manuales y la corrección ortotipográfica para asegurar un tono profesional en cada documento.

3. Fórmulas Excel

Asistencia en la lógica y sintaxis de fórmulas avanzadas como BUSCARV, SUMAR.SI y validación de datos complejos en hojas de cálculo.

4. Diseño Web

Generación de código, estructura y estilos (HTML/CSS/JS) para crear esta interfaz web, conectando APIs e integrando Supabase como base de datos.
