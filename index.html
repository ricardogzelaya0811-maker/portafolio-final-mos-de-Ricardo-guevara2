Sobre Mí

Soy Ricardo Zelaya, un estudiante comprometido con el dominio de las herramientas de productividad Microsoft Office, actualmente en preparación para obtener la certificación Microsoft Office Specialist (MOS). Mi interés por la tecnología me ha llevado a explorar no solo el uso estándar de las aplicaciones, sino también su integración con inteligencia artificial para optimizar procesos y elevar la calidad del trabajo profesional.

A lo largo de este portafolio presento una selección de documentos que evidencian mi competencia en el manejo avanzado de Microsoft Office. Cada proyecto fue desarrollado con atención al detalle y apoyo de herramientas de IA, reflejando mi capacidad para combinar habilidades técnicas con pensamiento analítico y creatividad orientada a resultados.

🐘 Proyecto técnico · PostgreSQL

De la instalación a tu primera base de datos.

Bitácora del proyecto

Instalación y creación paso a paso

Cada captura pertenece al proceso realizado. Desplázate para recorrer la instalación, la configuración inicial y la consulta de los datos creados.

Paso 01 · Sitio oficial

Conocer PostgreSQL

Ingresé al sitio oficial para iniciar el proceso desde una fuente confiable.

01

Paso 02 · Descargas

Seleccionar la plataforma

Desde la sección de descargas elegí el sistema operativo Windows.

02

Paso 03 · Windows

Elegir el instalador

Seleccioné la versión de PostgreSQL disponible para Windows de 64 bits.

03

Paso 04 · EDB

Descargar el ejecutable

La página de EDB inició la descarga del instalador oficial.

04

Paso 05 · Progreso

Esperar la descarga

Verifiqué que el archivo se descargara por completo antes de ejecutarlo.

05

Paso 06 · Archivo

Ubicar el instalador

Con la descarga terminada, localicé el ejecutable de PostgreSQL en el explorador de archivos.

06

Paso 07 · Inicio

Abrir el asistente

Ejecuté el archivo y comenzó el asistente de instalación de PostgreSQL.

07

Paso 08 · Directorio

Definir la instalación

Seleccioné la ubicación donde se instalarían los archivos del programa.

08

Paso 09 · Componentes

Elegir las herramientas

Mantuve PostgreSQL Server, pgAdmin 4 y las utilidades de línea de comandos.

09

Paso 10 · Datos

Definir el directorio de datos

Elegí la carpeta donde el servidor guardaría las bases de datos.

10

Paso 11 · Seguridad

Crear la contraseña

Configuré la contraseña del usuario administrador postgres.

11

Paso 12 · Puerto

Confirmar la conexión

Dejé el puerto predeterminado 5432 para las conexiones a PostgreSQL.

12

Paso 13 · Región

Ajustar la configuración regional

Confirmé los valores regionales antes de continuar con la instalación.

13

Paso 14 · Resumen

Revisar los ajustes

Verifiqué rutas, componentes, puerto y usuario antes de instalar.

14

Paso 15 · Confirmación

Preparar la instalación

El asistente indicó que PostgreSQL estaba listo para instalarse.

15

Paso 16 · Instalación

Instalar PostgreSQL

Esperé mientras el programa copiaba y configuraba todos los componentes.

16

Paso 17 · pgAdmin

Buscar la herramienta

Al terminar la instalación, busqué pgAdmin 4 desde el menú Inicio.

17

Paso 18 · Carga

Iniciar pgAdmin

Esperé que pgAdmin cargara su interfaz de administración.

18

Paso 19 · Panel

Conocer la interfaz

Se abrió el panel desde donde se administran servidores y bases de datos.

19

Paso 20 · Verificación

Comprobar pgAdmin

Verifiqué que la herramienta estuviera abierta y lista para administrar el servidor.

20

Paso 21 · Preferencias

Revisar la interfaz

Accedí a las preferencias para comprobar las opciones del entorno de trabajo.

21

Paso 22 · Aplicar

Actualizar la configuración

Confirmé la actualización de la interfaz tras cambiar las preferencias.

22

Paso 23 · Listo

Trabajar en pgAdmin

Con pgAdmin configurado, continué hacia la creación de la base de datos.

23

Paso 24 · Crear

Abrir una nueva base

Desde el explorador de objetos seleccioné la opción para crear una base de datos.

24

Paso 25 · Base

Crear rica_colegio

Ingresé el nombre rica_colegio y guardé la nueva base de datos.

25

Paso 26 · SQL

Crear la tabla y registros

Ejecuté CREATE TABLE e INSERT INTO para registrar a los estudiantes.

26

Paso 27 · Consulta

Comprobar los registros

Ejecuté una consulta para visualizar la tabla estudiantes y sus datos guardados.

27

Paso 28 · Excel

Comprobación final

Finalmente validé los estudiantes, las notas y el estado de aprobación desde Excel.

28

Resultado: una base de datos lista para consultar
